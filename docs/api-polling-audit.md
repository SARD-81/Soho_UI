# API Polling Audit

این audit تاریخی با polling contract نگهداری‌شده‌ی فعلی جایگزین شده است.

از اسناد زیر به‌عنوان source of truth استفاده کنید:

- [`04-core-flows/polling-and-data-refresh.md`](./04-core-flows/polling-and-data-refresh.md)
- [`04-core-flows/server-state-and-cache.md`](./04-core-flows/server-state-and-cache.md)

Audit قدیمی شامل observationهای مربوط به یک مقطع زمانی بوده که دیگر با تمام hookهای فعلی هم‌خوان نیستند. این compatibility file عمداً نگه داشته شده تا linkهای قدیمی break نشوند.

مقدارهای live مربوط به polling را در این فایل نگهداری یا update نکنید.
